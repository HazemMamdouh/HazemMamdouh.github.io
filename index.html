— LLM & Agentic Systems

  • Built agentic LLM workflows with LangGraph — agents modeled as directed graphs with message passing, tool-calling, and execution orchestration across nodes — plus custom orchestration and RAG services on Python + FastAPI.
  • Developed RAG systems with LlamaIndex: embedding fine-tuning, retrieval orchestration, synthetic QA generation, and multi-modal pipelines over text, charts, and research papers, backed by a FAISS vector store.
  • Engineered a long-document RAG path (recursive + sequential summarization) with NeMo Guardrails intent routing between retrieval and summarization, holding time-to-first-token under 5 seconds.
  • Built an LLM evaluation framework integrating Ragas (context relevancy/recall, faithfulness, answer relevancy) and LangSmith for tracing and continuous evaluation; added MT-Bench (LLM-as-judge), AlpacaEval, LM-Eval, Elo, perplexity, and a concurrency/latency benchmark measuring per-token timing under load.
  • Built Multi-RAG pipelines (multi-source retrieval, hybrid search, reranking), improving Recall@10 ~20% and reducing hallucinations ~30%.

— Speech · ASR & TTS

  • Fine-tuned Whisper for Arabic ASR to 7.5% WER on Modern Standard Arabic, then extended the model to Saudi dialect on noisy broadcast audio at 37% WER — on par with the best published fine-tuned results for that dialect.
  • Shipped a multilingual, multi-dialect TTS voice stack on Coqui XTTS-v2 — two speakers across English, Arabic MSA and Saudi — at 4.1 average MOS and 3.5 MOS naturalness, with a single voice identity holding across all three variants.
  • Delivered the surrounding telephony stack for 8 kHz narrowband audio: multilingual ASR on NVIDIA NeMo (Conformer/CTC) across MSA, Egyptian, Saudi and Gulf plus English, speaker diarization, VAD and noise suppression, keyword/hotword spotting, intent classification and NER.

— Computer Vision & Edge

  • Built an in-house visual-prompt detector (region-prompt contrastive alignment) that adapts to new domains from a few reference images with no re-training or re-labeling — +3 AP over YOLOE.
  • Fine-tuned and quantized OpenVLA for task-specific robotic manipulation, cutting memory footprint and latency enough to run the policy on-device rather than off-loading to a server.
  • Deployed real-time video analytics on NVIDIA Jetson across 10+ camera feeds / 5+ sites, sustaining 25–35 FPS with <150 ms latency for tracking, counting, and behavior analytics.
  • Built PPE compliance detection (Aramco) at 94% precision / 90% recall, reducing false alarms 25% via post-processing and threshold calibration.
  • Built CCTV violence detection (spatio-temporal modeling), reaching F1 ~84% from only 10 minutes of labeled data, cutting annotation time ~80% via a semi-automated labeling workflow with active-learning data selection.
  • Developed thermal/IR image-processing algorithms: fog dehazing/defogging to restore visibility in low-visibility conditions, and optical-flow-based detection of anomalous motion on IR feeds.
  • Tuned detection + multi-object tracking for “Easier Gates” flow analytics, reaching 94% flow accuracy and reducing ID switches by 14%.
  • Optimized inference via ONNX export and TensorRT acceleration, cutting per-stream latency ~35%; implemented dense-scene people counting, reducing counting error (MAPE) ~43%.

— Document AI & OCR

  • Built Arabic layout analysis and complex graphics-component analysis — 98% F1 on layout regions, 93% F1 on graphics components, and 84% on graphics reasoning (chart and diagram semantics, figure–caption linkage).
  • Fine-tuned PaddleOCR for Arabic text recognition — 14% WER general and ~8% WER domain-specific — handling cursive script, ligatures, and right-to-left layout.
